
# Experiment 3 - Responsive Food Ordering Website

## Aim
To develop a responsive food ordering website using CSS Grid and Flexbox.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Container Queries

## Features
- Responsive navigation bar
- Six restaurant cards
- Food categories
- Hover effects
- Mobile-friendly layout
- Tablet and desktop layouts

## Output
BiteRoute - Food Discovery and Ordering Website.

## Result
Successfully developed a responsive food ordering website using HTML and CSS.
